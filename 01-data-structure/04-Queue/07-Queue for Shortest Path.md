# Queue for Shortest Path

#### 1. Definition — Must Know

1. In an **unweighted graph** (every edge counts as 1 step), BFS with a queue finds the **shortest path** from a start to every other node.
2. The first time BFS reaches a node is the **shortest** way to it.
3. Store a **distance** (and optionally a **parent**) for each node. The parents let you rebuild the path.

#### 2. Why It Is Used — Must Know

1. "Minimum number of moves/steps/changes" questions are shortest-path questions in disguise.
2. It is simpler and faster than Dijkstra when edges have equal cost.
3. The same idea works on graphs, grids, words (Word Ladder), and puzzle states.

#### 3. How It Works — Must Know

```text
Graph:   0 — 1 — 2 — 5
         |        |
         3 ———————4

edges: 0-1, 1-2, 2-5, 0-3, 3-4, 4-2

Shortest path from 0 to 5?

queue [0]                dist: 0→0
take 0:  1, 3            dist: 1→1, 3→1       parent: 1←0, 3←0
take 1:  2               dist: 2→2            parent: 2←1
take 3:  4               dist: 4→2            parent: 4←3
take 2:  5 (and 4 seen)  dist: 5→3            parent: 5←2

Path: follow parents from 5 back to 0:  5 ← 2 ← 1 ← 0     →   0 → 1 → 2 → 5   (3 steps)
```

**Why BFS is correct:** the queue handles all nodes at distance `d` before any node at distance `d + 1`. So when a node is first discovered, no shorter way exists.

#### 4. Core Concepts — Must Know

1. **`dist` array** (start with `-1` = not reached). It doubles as the visited marker.
2. **`dist[next] = dist[node] + 1`** when you first reach `next`.
3. **`parent` array** to rebuild the path: follow `parent` from the target back to the start, then reverse.
4. **Stop early** when you reach the target.
5. **Only for equal edge weights.**

| Edge weights | Algorithm |
|---|---|
| All equal (1) | BFS |
| Only 0 or 1 | 0-1 BFS (deque) |
| Positive, different | Dijkstra (priority queue) |
| Negative possible | Bellman-Ford |

6. **Implicit graphs:** the "node" can be a word, a board, a lock code, a number. Neighbours are generated by rules.
7. **Why not DFS?** DFS finds *a* path, not the shortest one.

#### 5. Algorithm — Must Know

```text
dist = all -1;  dist[start] = 0;  queue = [start]
while queue is not empty:
    node = removeFirst()
    if node == target: done
    for each neighbour:
        if dist[neighbour] == -1:
            dist[neighbour] = dist[node] + 1
            parent[neighbour] = node
            addLast(neighbour)
answer = dist[target]  (or -1 if never reached)
```

#### 6. Kotlin Implementation — Must Know

```kotlin
// Shortest path (node list) in an unweighted graph; empty list if unreachable
fun shortestPath(graph: List<List<Int>>, src: Int, dst: Int): List<Int> {
    val dist = IntArray(graph.size) { -1 }
    val parent = IntArray(graph.size) { -1 }
    val queue = ArrayDeque<Int>()

    dist[src] = 0
    queue.addLast(src)

    while (queue.isNotEmpty()) {
        val node = queue.removeFirst()
        if (node == dst) break
        for (next in graph[node]) {
            if (dist[next] == -1) {
                dist[next] = dist[node] + 1
                parent[next] = node
                queue.addLast(next)
            }
        }
    }

    if (dist[dst] == -1) return emptyList()
    val path = mutableListOf<Int>()
    var cur = dst
    while (cur != -1) {
        path.add(cur)
        cur = parent[cur]
    }
    return path.reversed()
}

// Only the number of steps
fun shortestDistance(graph: List<List<Int>>, src: Int, dst: Int): Int {
    val dist = IntArray(graph.size) { -1 }
    val queue = ArrayDeque<Int>()
    dist[src] = 0
    queue.addLast(src)
    while (queue.isNotEmpty()) {
        val node = queue.removeFirst()
        if (node == dst) return dist[node]
        for (next in graph[node]) {
            if (dist[next] == -1) {
                dist[next] = dist[node] + 1
                queue.addLast(next)
            }
        }
    }
    return -1
}

// Implicit graph: minimum number of operations to turn `start` into `target`
// allowed moves: +1, -1, *2   (a small example of "states as nodes")
fun minOperations(start: Int, target: Int, limit: Int = 10_000): Int {
    val dist = HashMap<Int, Int>()
    val queue = ArrayDeque<Int>()
    dist[start] = 0
    queue.addLast(start)
    while (queue.isNotEmpty()) {
        val x = queue.removeFirst()
        if (x == target) return dist.getValue(x)
        for (next in intArrayOf(x + 1, x - 1, x * 2)) {
            if (next in 0..limit && next !in dist) {
                dist[next] = dist.getValue(x) + 1
                queue.addLast(next)
            }
        }
    }
    return -1
}
```

Check: on the graph above, `shortestPath(graph, 0, 5)` → `[0, 1, 2, 5]`. `minOperations(2, 7)` → `3` (for example `2 → 3 → 6 → 7`; no two-move route reaches `7`).

#### 7. Time & Space Complexity — Must Know

| Part | Cost |
|---|---:|
| Time | `O(V + E)` |
| Space (`dist`, `parent`, queue) | `O(V)` |
| Path rebuild | `O(path length)` |

For a grid with `R × C` cells: `O(R · C)`.

#### 9. Edge Cases / Common Mistakes

1. Using BFS on a **weighted** graph.
2. Marking visited when you take the node out, not when you add it.
3. Forgetting to set `dist[start] = 0`.
4. Start equals target: the answer is `0` steps and the path is `[start]`.
5. Unreachable target: return `-1` or an empty path. Do not follow `parent` from `-1`.
6. Rebuilding the path but forgetting to reverse it.
7. Returning the number of **nodes** when the question asks for **edges** (or the reverse). Check the statement.
8. Huge implicit state spaces without a limit.

#### 10. When to Use / When Not to Use

**Use when:**

1. Every move costs the same and you want the minimum number of moves.

**Avoid when:**

1. Costs differ (Dijkstra) or can be negative (Bellman-Ford).
2. You need all shortest paths or counts of them. Add a count array to BFS.

#### 12. Interview Must Remember

1. **BFS gives the shortest path when all edges cost 1.**
2. First time reached = shortest distance. Use `dist` as both distance and visited.
3. Keep `parent` to rebuild the path, then reverse it.
4. Weighted → Dijkstra. Weights 0/1 → 0-1 BFS.
